# Color Detection (ENSI Competition - First Task)

This project simulates the **first task of the ENSI competition**, which consists of detecting and identifying **red** and **blue** colors using the computer's webcam.  

The program uses **OpenCV** with **HSV color filtering** and draws bounding boxes with labels around detected colored objects.

---

## 🚀 Features
- Detects **Red** and **Blue** objects in real-time from the webcam.  
- Uses **HSV color space** for robust color detection.  
- Displays bounding boxes and text labels for identified colors.  
- Press **`q`** to quit the program.
