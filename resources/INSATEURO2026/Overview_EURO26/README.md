# INSAT Eurobot 2026 – ENSI COMPETITION OVERVIEW

Welcome to the **INSAT Eurobot 2026** GitHub Organization. This repository serves as the central overview for all team projects, documentation, and coordination.

---

## Organization Purpose

The INSAT Eurobot 2025 team is dedicated to designing, building, and programming a competitive autonomous robot for the Eurobot competition. Our goals include:

* Developing a robust computer vision system for arena element recognition.
* Implementing reliable ROS 2-based navigation and state machine control.
* Ensuring mechanical, electrical, and software integration.
* Maintaining clean, collaborative, and version-controlled code for all team members.

## Collaboration Guidelines

* **Branches & PRs**: Use feature branches (e.g., `feat/vision-detection`) and open Pull Requests for review before merging into `main`.
* **Commit Messages**: Follow clear, descriptive commit messages.
* **Issues & Tracking**: All tasks, bugs, and feature requests should be logged in GitHub Issues.
* **Data & Models**: Share large datasets or trained models via Roboflow or cloud storage, not directly in repos.
