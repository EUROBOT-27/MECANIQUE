EUROBOT 2027 - COMMANDS CHEAT SHEET
===================================

DAILY ROUTINE
-------------
/start      Type this when you open a session.
            Claude reads STATUS.md, TODO.md, the last log and the timeline, then
            gives a short briefing: days left, last session, what's open,
            suggested focus for today.

/wrap       Type this BEFORE you close the session.
            Claude writes today's log (logs/YYYY-MM-DD.md), updates TODO.md and
            STATUS.md, and checks every decision made today is in the decision log.
            -> If you forget it, the day's discussion is lost (only files survive).


THINGS YOU CAN JUST SAY (plain words, no command needed)
--------------------------------------------------------
"log this decision"            -> adds an entry to project/decisions.md
"add to todo: ..."             -> adds a task to TODO.md
"ask the rules-checker: ..."   -> sends a rules question to the rules-checker agent
                                  (it reads the official rules and cites sections)
"add this to the FAQ list"     -> adds an unclear rule to the questions for the referees
"index the new resources"      -> Claude skims new files in resources/ once and adds them to resources/INDEX.md
"how did other teams do X?"    -> Claude checks resources/INDEX.md and opens only the relevant ones


USEFUL BUILT-IN CLAUDE CODE COMMANDS
------------------------------------
/clear      Start a fresh conversation (do /wrap first!)
/compact    Shrink a long conversation to free up space
/resume     Re-open an earlier conversation
/context    See how full the conversation is
/memory     View / edit Claude's memory files
/help       All commands

! <cmd>     Run a terminal command yourself, e.g.  ! git status
Esc         Stop Claude in the middle of an answer
Esc Esc     Go back and edit / rewind an earlier message
Shift+Tab   Switch permission mode (normal / auto-accept / plan)
