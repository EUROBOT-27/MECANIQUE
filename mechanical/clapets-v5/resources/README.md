# Resources

- `mg996r/`: a 3D model of the MG996R servo (body, horn screws, cable grommet), added by Maatoug on 2026-10-29 and used
  as the servo reference in `fc/v5_fc.py` (only `mg996R_v2.step` is needed). **Source/licence: add before sharing
  publicly** (it was downloaded, not drawn by us).
- The butterfly plate is not a file here: its outline and holes were read from the Two Trees Bluer V2 printer model
  (a downloaded `.3dm`, 181 MB, kept in the team hub) and saved as `fc/plaque_papillon_reelle.json`.
